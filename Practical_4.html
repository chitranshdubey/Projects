Web Development Tutorial

Websites are commonly made using HTML, CSS, and JavaScript.

1. HTML makes the content

HTML adds things like headings and paragraphs to a webpage.

Example: <h1>Hello!</h1>

2. CSS changes how it looks

CSS changes colors, text sizes, and spacing.

Example: color: blue;

3. JavaScript adds actions

JavaScript can make a webpage respond when someone clicks a button.

Example: alert("Hello!");
